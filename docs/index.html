把 Mac 的空间找回来

8 个功能，覆盖缓存清理、空间分析、重复文件、应用卸载与磁盘体检。 所有删除都移入废纸篓，可随时恢复。

8 个功能 通用二进制 macOS 15.0+ 无外部依赖 零遥测

三步开始

无需配置，打开即用

1

扫描

左侧选页面，点「快速扫描」。想找大文件就用「深度扫描」。

2

勾选

逐项挑选，或点「全选安全项」一键选中低风险内容。

3

清理

确认后移入废纸篓，释放量会记进历史，随时可还原。

八个功能

侧边栏分三组，从清理到体检

清理
存储

清理

扫描缓存、日志与开发残留，按类别和风险分级呈现。

  • 磁盘总览 — 环形图显示占用比例，空间紧张时主动预警
  • 类别环形图 — 点击扇区或图例即可筛选
  • 明细列表 — 逐项勾选，带风险标签与「在访达中显示」
  • 快速扫描查常见位置，深度扫描额外找大文件
空间
存储

空间

只读地看清「空间去哪了」，逐层钻取到具体目录。

  • 矩形树图 — 面积正比于体积，颜色区分可清理与受保护
  • 悬停看详情，单击钻取，双击在访达中显示
  • 可切换列表视图，面包屑随时返回上层
  • 两阶段加载：先出目录骨架，再逐个回填体积

重复文件
存储

重复文件

按内容而非文件名判断，三阶段筛选逐层淘汰。

  • 按体积分组 — 只读元数据，体积唯一的直接排除
  • 头部指纹 — 只读前 4 KB 做 SHA256
  • 完整哈希 — 只有前两关都过了才读整文件
  • 默认一个都不勾选；批量勾选必留一份，不存在删空的路径
  • 跳过小文件、符号链接与硬链接
内存
系统

内存

实时内存观测面板，每 10 秒刷新。只读，不会结束任何进程。

  • 压力环 — 已用比例 + 压力等级（正常 / 偏高 / 紧张）
  • 内存构成 — 堆叠条展示各部分的互斥占比
  • 进程排行 — 常驻内存占用最高的应用
  • 交换空间用量，以及可手动回收的文件缓存
应用卸载
工具

应用卸载

把 .app 拖进废纸篓只删掉程序本体，缓存在 ~/Library 里的数据会永久留下。这一页按 bundle identifier 把残留一并找出。

  • 左侧列出每个应用的本体体积与残留体积
  • 右侧把残留按 ~/Library 子目录分组，逐项可勾选
  • 三个动作：清理残留（保留应用）/ 仅卸载本体 / 彻底卸载
  • 只做目录列举与名称匹配，不递归遍历，所以很快
卸载残余
工具

卸载残余

应用已经删了，只留下一堆无主文件。判定一个文件是否无主比看上去难，这里用了三个信号。

  • 递归读取应用内全部标识 — 只读顶层会读到 29 个，递归则 937 个
  • 读取 entitlements 声明的容器 — 有些容器名根本不在 Info.plist 里
  • 覆盖非标准安装位置 — 如 macFUSE 装在 /Library/Filesystems
  • 剥离沙盒 team-id 前缀；30 天内访问过的一律跳过
  • 保守优先：宁可漏报，不可误删

清理历史
工具

清理历史

每次清理后记一条，看清长期趋势与哪类最占空间。

  • 汇总卡片：累计释放 / 清理次数 / 清理项目 / 最近一次
  • 每日柱状图，近 7 / 30 / 90 天可切换
  • 按类别累计，一眼看出大头在哪
  • 只记体积不记路径 —— 历史文件里没有你的文件名
磁盘健康
工具

磁盘健康

文件系统、APFS 容器、快照与 SMART 状态，全部只读。

  • 启动卷 — 卷名、文件系统、挂载点、加密、容量占比
  • APFS 容器 — 容量 / 已用 / 未分配，卷数与快照数
  • 本地快照 — Time Machine 快照列表
  • SMART — 磁盘自检结果
💡

Apple Silicon 内置盘的多数 SMART 细项不可读，外接盘可能连总体状态也读不到。 读不到时界面显示「不可读」，不会编造数值。

四层安全防护

清理软件最大的风险是误删用户数据

✓

白名单路径

只有明确列出的路径才允许删除，全部位于缓存与日志区域。

✕

黑名单优先

即使误入白名单也会被拦下。文档、桌面、照片、密钥链一律不碰。

↗

路径穿越防护

先标准化再校验，.. 逃逸与软链接都会被识破。

♻

移废纸篓

不做永久删除。删错了从废纸篓取回即可。

🛡️

允许清理的位置仅限这些（~ 表示你的用户目录）：

~/Library/Caches ~/Library/Logs ~/.Trash ~/.npm/_cacache ~/.npm/_npx ~/.npm/_logs ~/Library/pnpm ~/.cache /private/var/folders

安装

首次打开需多一步

⚠️

本应用未做 Apple 公证。首次打开如提示「无法验证开发者」： 在「应用程序」里右键点击 MacCleaner → 选「打开」→ 再点「打开」。只需一次。

⌨️

也可以运行这条命令绕过检查：
xattr -d com.apple.quarantine /Applications/MacCleaner.app
